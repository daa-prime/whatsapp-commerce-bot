Business verification, production number & payment method

Verify the real business, register their production WhatsApp number, and add a payment method to the Meta app (it's free to add — you're only charged per message later).

Generate a System User access token

In Business Settings → Users → System Users, generate a System User access token. Do not use the default temporary token from the API Setup page — it expires roughly every 24 hours, while a System User token doesn't.
